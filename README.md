# Lista della Spesa Pro+ — PWA

Questa cartella contiene l'app pronta per la pubblicazione come Progressive Web App.

## Pubblicazione

Pubblica tutti i file mantenendo la stessa cartella (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`) su un hosting HTTPS. Per lo sviluppo locale usa `localhost`; l'apertura diretta del file HTML (`file://`) non permette l'installazione PWA.

Il pulsante **Scarica / Installa app** si mostra quando l'app non è aperta in modalità installata. Nei browser che supportano l'installazione propone il prompt nativo; negli altri mostra le istruzioni per aggiungerla alla schermata Home.
